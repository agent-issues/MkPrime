## Steps

### 1. Roxygen `@param` tags in `MkPrimeModel()`

**File**: `R/MkPrimeModel.R` (lines 5–32 roxygen block)

Add four new `@param` entries after the existing `rateNeoMeanlog/Sdlog`
pair (before `@return`):

```
@param qHeterogeneity Logical. Enable Q-matrix heterogeneity across
  characters via discretised Dirichlet-marginal equilibrium frequencies?
  Default `FALSE`. When enabled, each character's likelihood is averaged
  over a set of F81 rate matrices whose equilibrium frequencies are drawn
  from Beta(`beta_scale`, (k - 1) * `beta_scale`), the marginal of a
  symmetric Dirichlet. Use for model comparison (e.g. stepping-stone
  marginal likelihood); not recommended as the default model.
@param nBetaCat Integer. Number of equal-probability Beta bins for the
  heterogeneity discretisation. Default `4L`. Higher values increase
  accuracy at the cost of compute time (scales linearly with `nBetaCat`).
@param betaScaleShape,betaScaleRate Shape and rate for the Gamma prior
  on `beta_scale` (the symmetric Dirichlet concentration parameter).
  Defaults: shape = 1, rate = 1.
```

Also add a `@section Q-matrix heterogeneity:` block with a concise
explanation of what the feature does and when to use it. Roughly:

- Single parameter `beta_scale` (= α) controls how unequal equilibrium
  frequencies can be across characters.
- Large α → all characters have nearly equal frequencies (JC); small α →
  characters can have strongly unequal frequencies (F81).
- The marginal of one component of Dirichlet(α, ..., α) with k
  components is Beta(α, (k−1)α), so the discretisation adapts
  automatically to the number of states in each character.
- For binary characters (k=2), this is exactly Beta(α, α) — symmetric.
- Cite Felsenstein 1981 for F81, Lewis 2001 for Mk.

### 4. Mathematical details in `@section` or standalone doc

The full mathematical derivation (Dirichlet marginal → Beta(α, (k−1)α),
rotation averaging, F81 closed-form P(t), composition with `rate_loss`)
is too long for an `@section` tag. Options:

**Option A**: Add a `details` vignette (`vignettes/het-details.qmd`) with
the full mathematical specification. Cross-reference from roxygen with
`vignette("het-details", package = "MkPrime")`.

**Option B**: Keep it in the `@section` block, condensed to ~15 lines
of LaTeX-free description with a pointer to the plan document for the
full derivation.

**Recommendation**: Option A. The maths is novel enough that a dedicated
vignette serves both users and reviewers. The vignette should cover:

1. Motivation (why heterogeneous equilibrium frequencies?)
2. The Dirichlet-marginal insight (Beta(α, (k−1)α) as the marginal)
3. Discretisation into B bins via quantile midpoints
4. Rotation for state-labelling symmetry
5. F81 transition probabilities (closed-form)
6. Composition with `rate_loss` for neomorphic characters
7. Computational cost analysis
8. Comparison with RevBayes multistate approach (brief)

Include the key equations rendered in LaTeX:

- π^(b,s)_s = β_b, π^(b,s)_j = (1 − β_b)/(k − 1) for j ≠ s
- P_{ij}(t) = π_j + (δ_{ij} − π_j) exp(−μt) where μ = k/(k − π_s²/(Σπ²))
  ... or more simply the standard F81 form.
- L_c ≈ (1/B)(1/k) Σ_b Σ_s L_c(π^(b,s))
